# ReactJS Filestructure Explaination ..
    - Node_modules folder is the backbone of project ..
    - public folder is the main folder of project where our main html file will be store ..
    - src folder is the main folder of project where our main js file will be store ..
    - package.json file is the main file of project where our main dependencies will be store ..
    - package-lock.json file is the main file of project where our main dependencies details will be store ..
